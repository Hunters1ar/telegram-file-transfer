03

The protocol, end to end.

Four steps. Approximately 900 milliseconds from upload to shareable ID.

01
T+0ms

Upload a file

Send any file up to 2GB directly to @hunterstar_bot. The bot receives the stream via Telegram's MTProto protocol — no HTTP middleman, no upload speed caps from third-party CDNs.

$ telegram.send(bot, file="report.pdf", chunk=512kb)
02
T+340ms

Receive File ID

A 32-character identifier is generated, hashed with BLAKE3, and stored in MongoDB alongside ciphertext metadata. The original filename is encrypted separately — even the database can't reconstruct it.

→ f9a2c7e1·b483·4d2e·9f1a·c7028e5d
03
T+520ms

Share with anyone

Distribute the File ID via any channel — Telegram, email, carrier pigeon. Public IDs resolve for anyone. Private IDs require the recipient to authenticate through Telegram. Temporary IDs self-destruct.

$ hunterstar.share(id, mode=private, ttl=24h)
04
T+900ms

Download instantly

Recipients query the bot with the File ID. Cloudflare R2 serves the file from the nearest of 330+ edge locations — typically under 80ms TTFB. No login walls, no advertising interstitials, no waiting rooms.

→ 200 OK · 4.2MB · 87ms TTFB · cf-r2-eu-west-1
